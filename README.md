# Kodik AdBlock

Расширение для Chrome / Edge, которое убирает рекламу в плеере Kodik.

## Как работает

1. **Перехват `/ftor`** — из ответа плеера вырезаются массивы `vast` / `reserve_vast` (основной источник preroll).
2. **Блокировка сетей** — Buzzoola, Adtec, VAST-хосты и др. через `declarativeNetRequest`.
3. **DOM** — снимает `#vpaid_iframe` и кликает «Пропустить», если что-то всё же проскочило.

## Установка

1. Скачайте `kodik-adblock-0.1.zip` из [Releases](https://github.com/NailNaMeste/kodik-adblock/releases).
2. Распакуйте архив в любую папку.
3. Откройте `chrome://extensions` (или `edge://extensions`) и включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите **распакованную** папку `kodik-adblock` (не сам zip).
5. Если расширение уже стояло — нажмите **Обновить** на карточке и перезагрузите вкладку с плеером.

## Проверка

Откройте любой ролик в плеере Kodik. В DevTools → Network в ответе `/ftor` поля `vast` и `reserve_vast` должны быть `[]`.
