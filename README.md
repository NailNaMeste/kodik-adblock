# Kodik AdBlock

Расширение для Chrome / Edge, которое убирает рекламу в плеере Kodik.

## Как работает

1. **Перехват `/ftor`** — из ответа плеера вырезаются массивы `vast` / `reserve_vast` (основной источник preroll).
2. **Блокировка сетей** — Buzzoola, Adtec, VAST-хосты и др. через `declarativeNetRequest`.
3. **DOM** — снимает `#vpaid_iframe` и кликает «Пропустить», если что-то всё же проскочило.

## Установка

1. `chrome://extensions` → **Режим разработчика**
2. **Загрузить распакованное** → папка `~/kodik-adblock`
3. Если расширение уже стояло — нажмите **Обновить** на карточке расширения и перезагрузите вкладку с плеером
